# GPU telemetry on Resources

Resources queries the fixed, permission-protected `GET /api/monitoring/vm/gpus` endpoint. It reads NVIDIA DCGM exporter series from the existing in-cluster VictoriaMetrics instance. Install and configure a compatible **DCGM exporter separately** on NVIDIA GPU nodes, and ensure its `/metrics` endpoint is scraped by VictoriaMetrics. The VictoriaMetrics chart already discovers pods annotated `prometheus.io/scrape: "true"`; annotate the exporter pod and set `prometheus.io/port: "9400"` if it exposes the default port. If network policies are enabled, add the exporter's namespace to `networkPolicy.scrapeNamespaces` in the VictoriaMetrics chart values and allow ingress from VictoriaMetrics to port 9400 in the exporter namespace. Drivers and Kubernetes GPU device plugins alone do **not** publish utilization or memory telemetry. Kubarr does not install an exporter.

The supported schema is NVIDIA's `DCGM_FI_DEV_GPU_UTIL` (percentage), `DCGM_FI_DEV_FB_USED` and `DCGM_FI_DEV_FB_FREE` (MiB). The exporter must provide `Hostname` (node) and `UUID` (device) labels; MIG `GPU_I_ID` / `GPU_I_PROFILE` distinguish instances. Used memory is converted to bytes; total is used + free only when both fresh samples exist. Each value is paired by full series labels with its source-sample timestamp from VictoriaMetrics `tlast_over_time(metric[120s])`; the instant query's evaluation timestamp is **not** a scrape timestamp. Source samples older than 120 seconds, malformed/nonfinite/out-of-range samples and samples more than 30 seconds in the future are ignored. An absent field renders **Unavailable**, including after scrapes stop; a measured zero stays zero. A failed VictoriaMetrics query reports GPU telemetry unavailable independently of CPU and memory monitoring. No GPU values are attributed to applications: these are device-level measurements, not allocations or per-pod utilization.

Intel and other vendors are currently **unsupported for utilization/memory telemetry** on this page. Installing an Intel device plugin or requesting an Intel GPU does not enable this NVIDIA-specific endpoint. A documented, stable exporter schema and corresponding implementation would be required for Intel monitoring.

Metric definitions and units: [NVIDIA dcgm-exporter collector CSV](https://github.com/NVIDIA/dcgm-exporter/blob/main/etc/dcp-metrics-included.csv); [NVIDIA DCGM exporter documentation](https://docs.nvidia.com/datacenter/cloud-native/gpu-telemetry/latest/dcgm-exporter.html). Source timestamp function: [VictoriaMetrics MetricsQL `tlast_over_time`](https://docs.victoriametrics.com/victoriametrics/metricsql/#tlast_over_time).
